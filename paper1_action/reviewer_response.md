# Paper 1 revision notes for coauthors

This revision treats the spiking network as a **decision core to characterize**, rather than claiming it is the best architecture or an energy-saving deployment. All SLURP test-set analyses remain exploratory because preliminary test results were inspected during development. The French acoustic and recognized-word protocols were recorded before their held-out scores were inspected.

| Reviewer concern | Revision and evidence |
|---|---|
| No demonstrated reason to prefer spiking | The title, abstract, discussion, and conclusion now state the measured tradeoff. We do not infer energy from firing activity or CPU timing. The GRU wins on both acoustic benchmarks. |
| Leak and initialization confound | Added an equal-parameter tanh core with 0.9 state leak and the spiking core's initial recurrent gain. On SLURP audio, SNN accuracy is 50.48% versus 50.64% for leaky tanh; the paired hierarchical 95% interval for the difference is −1.22 to +0.98 points. On French audio, leaky tanh leads by 1.93 points. |
| Possible 30-second Whisper padding | Audited feature extraction: variable-length recordings enter the encoder, and pooling uses only returned valid states. A 2.72-second waveform produces 137 encoder states before 32-step pooling. The feature cache and linear-probe fit were not changed by this clarification, explaining the identical 51.68% probe result. |
| Low absolute accuracy and label mismatch | Clarified that the 60 choices are SLURP's combined scenario/action labels. Added the original SLURP combined-label scores for context and a word/bigram text baseline (79.09% on oracle text; 62.41% on ASR words). These comparisons use different upstream/classifier protocols. |
| Gold-to-ASR train/test shift | Added five-seed text-core runs trained on ASR hypotheses from training audio. Test accuracy becomes 56.04% plain tanh, 58.02% leaky tanh, 59.05% spiking, and 58.97% GRU. The spiking-minus-leaky-tanh hierarchical 95% interval is −0.02 to +2.02 points. |
| One inspected dataset | Added French Speech-MASSIVE recordings as a separately collected, prospectively fixed acoustic replication. The official test files required authentication, so the protocol reserved validated official-validation files for held-out evaluation. French speakers and recordings differ; the 60-intent ontology is related to SLURP. |
| EasyCall does not support accessibility claims | Kept it brief as a secondary failure test, reporting low correct-execution coverage, false noncommand execution, and incorrect emergency-call executions. No deployment, clinical, or accessibility benefit is claimed. |
| Ambiguous threshold notation | Wrote the threshold explicitly as `H(\tilde v_t-\vartheta)` with `\vartheta=1`. |
| Three seeds and limited uncertainty | Expanded primary and French core comparisons to five seeds and used a paired hierarchical bootstrap over seeds and utterances. EasyCall retains three speaker-disjoint seeds and a speaker-cluster interval. |
| Deferral and calibration unclear | Defined the development threshold as the largest confidence-ranked prefix at no more than 10% development error. Reported AURC, before/after ECE, a reliability chart, and the always-defer cost baseline. Test error is not guaranteed to stay under 10%. |
| Strongest text model absent from deferral analysis | Added the TF--IDF logistic fit to the ASR and oracle risk curves and ASR calibration table. On ASR words its temperature-scaled ECE is 0.028, AURC is 0.149, and development-selected test cost at a 0.2 deferral cost is 0.1518, beating the recurrent spiking core's 0.063, 0.176, and 0.1566 respectively. The baseline is one fit versus five-seed recurrent means. |
| SLURP text lead lacked a fresh replication | Ran the prospectively fixed French recognized-word comparison on 2,031 held-out recordings, using the same four recurrent cores and five seeds. Spiking averages 42.68% and leak-matched tanh 41.31%, a +1.37-point mean lead. The paired seed-and-utterance hierarchical 95% interval is −0.01 to +2.77 points, so the direction repeats but evidence for a true advantage remains inconclusive. GRU reaches 44.37% and TF--IDF reaches 50.81%. Prompt-referenced ASR word error rate is 44.73%. |
| Missing related work and crowded citations | Added Cramer, Yin, Bittar and Garner, Blouw, and two relevant Banad-group papers. The author's earlier hardware survey is cited only as background for future implementation work. |
| Presentation details | Replaced the placeholder affiliation, shortened the abstract, added color accuracy/risk/reliability figures, and removed a visually weak risk-band claim. |

## Remaining boundaries

The spiking core remains a dense software implementation with analog input and output. The present evidence does not establish an energy benefit, real-time interaction latency, or safe assistive control. Adaptive-threshold spiking units and measured neuromorphic deployment are future experiments, not results of this paper.
